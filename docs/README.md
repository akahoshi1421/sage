# sage(セージ)

これはAI時代に新しいライブラリを効率的に学ぶためのフレームワークです。TypeScriptの型パズルを学ぶtype-challengesおよびそれをwebで完結できるようにした`https://mosya.dev/type-challenges`から着想を得ています。

ただし、学ぶのはTypeScriptの型パズルに決まった話ではありません。任意の技術、ライブラリ、フレームワークについて学べるようにするためのフレームワークです。
たとえば利用者がvitestを学ぶために「type-challenges風vitest学習」だったり、Pythonのnumpyを学ぶために「type-challenges風numpy学習」だったり対象は任意のものが入ります。
